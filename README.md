# SALLOW

A box of 25 pocket universes on a kid's PC. Dive through their folds, stop at stars, change their sky, watch what the people below make of it.

Portrait mobile PWA: TypeScript, WebGL2, a sim Worker. Deterministic: the same serial is the same universe everywhere.

```
npm ci
npm run dev        # app at /, demo gallery at /dev
npm run check      # typecheck + lint + test
npm run e2e        # Playwright smoke at 390x844 (PW_CHROMIUM=/path to use a local browser)
```

Start with `CLAUDE.md`, then `docs/ARCHITECTURE.md`, `docs/DESIGN.md` and `docs/UNITS.md`.
